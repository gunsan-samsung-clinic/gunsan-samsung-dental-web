# 마케팅 담당자용 — 이미지·릴스 올리기 가이드

이 문서는 홈페이지 이미지/영상 관리를 맡은 마케팅 담당자를 위한 가이드입니다.
병원 관리자 화면(admin.html)은 다루지 않고, **GitHub에 이미지·영상 파일을 올리는 방법만** 다룹니다.

---

## 0. 준비 (병원장님/개발자가 먼저 해주세요)

마케팅 담당자가 파일을 올리려면 먼저 저장소에 "협업자"로 초대되어야 합니다.

1. `https://github.com/gunsan-samsung-clinic/gunsan-samsung-dental-web` 저장소 페이지 접속 (관리 권한 있는 계정으로 로그인)
2. 상단 **Settings** 클릭
3. 왼쪽 메뉴 **Collaborators** 클릭
4. **Add people** 클릭 → 마케팅 담당자의 GitHub 아이디 또는 이메일 입력 → 초대
5. 마케팅 담당자는 이메일로 온 초대 링크를 열고 **수락(Accept)** 해야 합니다 (본인 GitHub 계정으로 로그인 필요, 계정이 없으면 `github.com`에서 먼저 무료로 만들어야 함)

이 단계를 건너뛰면, 마케팅 담당자가 파일을 올리려 할 때 권한 오류가 나거나 본인 개인 복사본(fork)에만 올라가고 실제 홈페이지에는 반영되지 않을 수 있습니다.

---

## 1. GitHub Desktop 설치

1. `https://desktop.github.com` 접속 → 다운로드 → 설치
2. 실행 후 **초대 수락한 GitHub 계정으로 로그인**

## 2. 저장소 내려받기 (클론)

1. GitHub Desktop에서 **File → Clone repository** 클릭
2. **URL** 탭 선택
3. 주소창에 아래를 입력:
   ```
   https://github.com/gunsan-samsung-clinic/gunsan-samsung-dental-web
   ```
4. 저장할 위치 선택 (예: 바탕화면) → **Clone** 클릭

이제 컴퓨터에 `gunsan-samsung-dental-web`이라는 폴더가 생깁니다. 이 폴더가 앞으로 작업할 곳입니다.

## 3. 이미지 추가하기

1. 방금 받은 폴더를 탐색기(윈도우 파일 탐색기)에서 엽니다
2. 새 이미지 파일을 이 폴더 **안에 그대로** 복사해서 붙여넣습니다 (드래그 앤 드롭도 가능)
3. 파일명 규칙:
   - **영어와 숫자만 사용** (한글, 띄어쓰기, 특수문자 넣지 마세요)
   - 예: `event-summer2026.jpg`, `notice-banner01.png`
4. 이미지를 올린 뒤에는 **그 파일명을 병원 관리자 담당자에게 전달**해주세요. 관리자 화면에서 이벤트를 등록할 때 그 파일명을 입력해야 실제로 이미지가 연결됩니다.

## 4. 릴스(영상) 교체하기

지금 홈페이지의 "릴스" 영상은 `videosevent1.mp4`라는 고정된 파일명을 쓰고 있습니다.

새 영상으로 바꾸려면:
1. 새 영상 파일의 이름을 **정확히 `videosevent1.mp4`로 변경**합니다
2. 저장소 폴더 안의 기존 `videosevent1.mp4`를 새 파일로 **덮어쓰기** 합니다

> 다른 이름으로 올리면 홈페이지에 자동으로 반영되지 않습니다. 반드시 같은 파일명을 유지해야 합니다.

## 5. GitHub Desktop에서 올리기 (Push)

1. GitHub Desktop을 열면 왼쪽에 바뀐(추가/교체된) 파일 목록이 보입니다
2. 왼쪽 아래 **Summary** 칸에 무엇을 바꿨는지 짧게 적습니다 (예: `7월 이벤트 이미지 추가`, `릴스 영상 교체`)
3. **Commit to main** 버튼 클릭
4. 상단의 **Push origin** 버튼 클릭

로그인 창이 뜨면 본인 GitHub 계정으로 로그인하면 됩니다.

## 6. 반영 확인

1~2분 정도 기다린 뒤, 실제 홈페이지 주소를 새로고침해서 이미지/영상이 잘 바뀌었는지 확인합니다.

- 일반 홈페이지: `https://gunsan-samsung-clinic.github.io/gunsan-samsung-dental-web/index.html`
- 고객 전용 페이지: `https://gunsan-samsung-clinic.github.io/gunsan-samsung-dental-web/customer.html`

---

## 주의사항

- **코드 파일(`.html`, `.js`, `.css`로 끝나는 파일)은 건드리지 마세요.** 이미지(`.jpg`, `.png`)와 영상(`.mp4`) 파일만 추가/교체하면 됩니다.
- 파일명에 한글, 띄어쓰기, 특수문자를 쓰면 홈페이지에서 이미지가 안 보일 수 있습니다.
- 이벤트 이미지는 파일을 올리는 것만으로는 화면에 안 나옵니다 — 병원 관리자가 관리자 화면에서 그 파일명을 입력해줘야 완성됩니다.
- 무엇을 바꿨는지 잘 모르겠거나 실수한 것 같으면, 개발 담당자에게 바로 문의해주세요.

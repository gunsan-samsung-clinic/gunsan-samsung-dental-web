# 마케팅 담당자용 — 이미지·릴스 올리기 가이드

이 문서는 홈페이지 이미지/영상 관리를 맡은 마케팅 담당자를 위한 가이드입니다.
병원 관리자 화면(admin.html)은 다루지 않고, **GitHub에 이미지·영상 파일을 올리는 방법만** 다룹니다.

---

## 0. 준비 (병원장님/개발자가 먼저 해주세요)

마케팅 담당자가 파일을 올리려면 먼저 저장소에 "협업자"로 초대되어야 합니다.

1. `https://github.com/gunsan-samsung-clinic/gunsan-samsung-dental-web` 저장소 페이지 접속 (관리 권한 있는 계정으로 로그인)
2. 상단 **Settings** 클릭
3. 왼쪽 메뉴 **Collaborators** 클릭
4. **Add people** 클릭 → 마케팅 담당자의 GitHub 아이디 또는 이메일 입력 → 초대
5. 마케팅 담당자는 이메일로 온 초대 링크를 열고 **수락(Accept)** 해야 합니다 (본인 GitHub 계정으로 로그인 필요, 계정이 없으면 `github.com`에서 먼저 무료로 만들어야 함)

이 단계를 건너뛰면, 마케팅 담당자가 파일을 올리려 할 때 권한 오류가 나거나 본인 개인 복사본(fork)에만 올라가고 실제 홈페이지에는 반영되지 않을 수 있습니다.

---

## 1. GitHub Desktop 설치

1. `https://desktop.github.com` 접속 → 다운로드 → 설치
2. 실행 후 **초대 수락한 GitHub 계정으로 로그인**

## 2. 저장소 내려받기 (클론)

1. GitHub Desktop에서 **File → Clone repository** 클릭
2. **URL** 탭 선택
3. 주소창에 아래를 입력:
   ```
   https://github.com/gunsan-samsung-clinic/gunsan-samsung-dental-web
   ```
4. 저장할 위치 선택 (예: 바탕화면) → **Clone** 클릭

이제 컴퓨터에 `gunsan-samsung-dental-web`이라는 폴더가 생깁니다. 이 폴더가 앞으로 작업할 곳입니다.

## 3. 사진(이미지) 넣는 법

폴더는 그냥 "사진을 담는 상자"라고 생각하시면 돼요. 그 상자 안에 새 사진을 넣기만 하면 됩니다.

1. 2번에서 받은 폴더(예: 바탕화면의 `gunsan-samsung-dental-web` 폴더)를 더블클릭해서 엽니다
2. 홈페이지에 쓸 사진 파일을 복사(Ctrl+C)해서, 방금 연 폴더 안에 붙여넣기(Ctrl+V) 합니다
   - 사진 파일 위에서 마우스로 그대로 끌어다 놓아도(드래그) 됩니다
3. **파일 이름은 꼭 영어와 숫자로만** 지어주세요 (한글 X, 띄어쓰기 X, 특수문자 X)
   - 좋은 예: `event-summer.jpg`, `banner01.png`
   - 안 좋은 예: `여름이벤트.jpg`, `배너 1.png`
4. 다 넣으셨으면, **그 파일 이름을 그대로 병원 관리자 담당자에게 카톡/문자로 전달**해주세요.
   - 사진만 올린다고 홈페이지에 바로 나오는 게 아니에요! 관리자 담당자가 그 화면에서 파일 이름을 한 번 더 입력해줘야 실제로 사진이 붙습니다. (파일명을 안 알려주면 아무 일도 안 일어나요.)

## 4. 릴스(영상) 넣는 법

이제 영상은 **여러 개를 동시에 등록**할 수 있고, 하나가 끝나면 자동으로 다음 영상으로 넘어가요.

1. 위 3번과 똑같은 방법으로, 영상 파일을 폴더 안에 복사해서 넣습니다
2. 영상 파일 이름도 영어와 숫자로만 짓습니다 (예: `reel1.mp4`, `reel2.mp4`)
3. 영상을 넣으신 뒤, **그 파일 이름을 병원 관리자 담당자에게 전달**해주세요. 그리고 "몇 번째로 재생됐으면 좋겠는지"도 같이 알려주시면 좋아요 (예: "이 영상이 제일 먼저 나왔으면 좋겠어요")
   - 관리자 담당자가 관리자 화면 "릴스" 탭에서 그 파일 이름과 순서를 등록해야 실제로 재생됩니다.

## 5. 내 컴퓨터에 있는 파일을 인터넷에 올리기 (Push)

지금까지는 **내 컴퓨터 안에서만** 파일을 넣은 상태예요. 아직 인터넷(진짜 홈페이지)에는 안 올라갔어요. 마지막으로 "인터넷에 보내기" 버튼을 눌러야 완성됩니다.

1. **GitHub Desktop 프로그램을 엽니다**
2. 왼쪽 화면에 방금 추가한 파일들이 목록으로 보일 거예요 (안 보이면 왼쪽 위 저장소 이름이 맞는지 확인)
3. 화면 왼쪽 아래에 있는 네모칸(**Summary**)에 뭘 바꿨는지 짧게 한 줄 적습니다
   - 예: `7월 이벤트 사진 추가`, `릴스 영상 2개 추가`
4. 그 아래 **"Commit to main"**이라고 써진 파란 버튼을 클릭합니다
5. 화면 위쪽에 있는 **"Push origin"** 버튼을 클릭합니다
   - 이게 실제로 인터넷에 보내는 버튼이에요. 이걸 눌러야 진짜 완료됩니다.
6. 혹시 로그인 화면이 뜨면, 본인 GitHub 아이디로 로그인하면 자동으로 이어서 진행됩니다

## 6. 반영 확인

1~2분 정도 기다린 뒤, 실제 홈페이지 주소를 새로고침해서 이미지/영상이 잘 바뀌었는지 확인합니다.

- 일반 홈페이지: `https://gunsan-samsung-clinic.github.io/gunsan-samsung-dental-web/index.html`
- 고객 전용 페이지: `https://gunsan-samsung-clinic.github.io/gunsan-samsung-dental-web/customer.html`

---

## 주의사항

- **코드 파일(`.html`, `.js`, `.css`로 끝나는 파일)은 건드리지 마세요.** 이미지(`.jpg`, `.png`)와 영상(`.mp4`) 파일만 추가/교체하면 됩니다.
- 파일명에 한글, 띄어쓰기, 특수문자를 쓰면 홈페이지에서 이미지가 안 보일 수 있습니다.
- 이벤트 이미지, 릴스 영상 모두 파일을 올리는 것만으로는 화면에 안 나옵니다 — 병원 관리자가 관리자 화면에서 그 파일명을 입력해줘야 완성됩니다. **파일명 전달을 꼭 잊지 마세요.**
- 무엇을 바꿨는지 잘 모르겠거나 실수한 것 같으면, 개발 담당자에게 바로 문의해주세요.
